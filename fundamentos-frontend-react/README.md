# Fundamentos de Front-End com React

Aplicação prática do Módulo 04, construída com Next.js, TypeScript, Tailwind CSS e App Router.

## Executar localmente

```bash
pnpm install
pnpm dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Prática implementada

- Componentes funcionais e props;
- Renderização de listas com `map` e `key` estável;
- Uso de `next/image` com texto alternativo;
- Rotas dinâmicas em `/estudos/[topic]`;
- Tipagem de `params` e uso de `async`/`await` no App Router.

## Verificação

```bash
pnpm lint
pnpm build
```
